# TeachersLog

TeachersLog は、先生の口頭での発言をクラスの生徒同士で確認し、伝達ミスや聞き間違いを減らすための Web アプリケーションです。

公開デモ: <https://game-manager.github.io/Tea-Log/>

## 解決したい課題

口頭での発言は、聞き漏らし・記憶違い・伝言時の抜けによって内容が変わることがあります。TeachersLog は、同じ発言を聞いた複数の生徒による確認を集め、一定人数に達した発言だけを保護者にも共有します。

## サービスの仕組み

1. 日直や係の生徒が、先生から聞いた発言を投稿します。
2. 同じ発言を聞いた生徒が内容を確認します。
3. 新規投稿は 5 人中 3 人以上の確認で「確認済み」になります。
4. 確認済みになった発言だけが保護者画面に自動で表示されます。
5. 投稿・確認・閲覧状況は Cloud Firestore を通じて利用者間で同期されます。

先生による入力・確認・承認はありません。複数人の確認は内容の完全性や正確性を保証するものではないため、生徒・保護者の詳細画面に注意書きを表示しています。

## 起動方法

Node.js 18 以上を用意し、次のコマンドを実行してください。

```bash
npm install
npm run dev
```

表示されたローカル URL（通常は `http://localhost:5173`）をブラウザーで開きます。

本番ビルドの確認：

```bash
npm run build
npm run preview
```

Firestoreへの保存と複数端末相当のリアルタイム同期テスト：

```bash
npm run test:sync
```

このテストはFirestore Emulatorを使い、端末A相当のクライアントから保存した発言が、端末B相当のリアルタイム購読へ反映され、さらに再読み込みした別クライアントから取得できることを確認します。端末A・Bが同時投稿した場合もFirestore Transactionによって両方が保存されることを検証します。実行にはFirebase CLIとJava 21以降が必要です。

- 生徒・保護者ごとのアプリ内通知
- 投稿者本人による発言削除と削除前確認
- Firestoreによる投稿・確認・閲覧状況のリアルタイム共有
- localStorageによる端末キャッシュ
- 学校ドメイン限定のGoogle認証
- クライアント検証とFirestore Security Rulesによる二重のアクセス制御
- 指定アカウント限定の管理者ダッシュボードとユーザー管理
- 管理者によるクラス切り替え、生徒／保護者画面の利用、発言モデレーション

- スマートフォンを優先したレスポンシブ UI
- 描画エラー時のフォールバック画面

## サンプルデータについて

仕様の「確認中 3/5 人」と、既定条件の「3 人以上で確認済み」を同時に表現するため、サンプルの「明日の部活動について」のみ必要確認人数を 4 人に設定しています。新しく投稿する発言は既定どおり 3 人で確認済みになります。

## 注意事項

- このリポジトリはプロトタイプです。実際のプッシュ通知は使用していません。
- データはFirestoreに保存され、localStorageにも端末キャッシュが残ります。
- 生徒・保護者ロールは初回登録時に選択し、登録後は管理者が修正できます。実運用では学校側の名簿データとの連携も検討してください。
- 学校の正式な情報共有手段を置き換えるものではありません。
