# TeachersLog

TeachersLog は、先生から口頭で伝えられた学校連絡をクラスの生徒同士で確認し、伝達ミスや聞き間違いを減らすための Web アプリケーションです。

## 解決したい課題

口頭連絡は、聞き漏らし・記憶違い・伝言時の抜けによって内容が変わることがあります。TeachersLog は、同じ連絡を聞いた複数の生徒による確認を集め、一定人数に達した連絡だけを保護者にも共有します。

## サービスの仕組み

1. 日直や係の生徒が、先生から聞いた連絡を投稿します。
2. 同じ連絡を聞いた生徒が内容を確認します。
3. 新規投稿は 5 人中 3 人以上の確認で「確認済み」になります。
4. 確認済みになった連絡だけが保護者画面に自動で表示されます。

先生による入力・確認・承認はありません。複数人の確認は内容の完全性や正確性を保証するものではないため、生徒・保護者の詳細画面に注意書きを表示しています。

## 起動方法

Node.js 18 以上を用意し、次のコマンドを実行してください。

```bash
npm install
npm run dev
```

表示されたローカル URL（通常は `http://localhost:5173`）をブラウザーで開きます。

本番ビルドの確認：

```bash
npm run build
npm run preview
```

## 主な機能

- 状態別（未確認・確認中・確認済み）の生徒向け連絡一覧
- 入力チェック付きの新規連絡投稿
- 生徒ごとに一度だけ行える内容確認
- 必要人数到達時の自動的な確認済み化と確認日時の保存
- 確認済み連絡だけを表示する保護者画面
- 保護者ごとの未読・閲覧済み管理
- 投稿、確認、確認済み連絡の履歴
- 生徒・保護者ごとのアプリ内通知
- 投稿者本人による連絡削除と削除前確認
- localStorage による投稿・確認・閲覧状況の永続化
- スマートフォンを優先したレスポンシブ UI
- 描画エラー時のフォールバック画面

画面下部またはフッターの「デモデータを初期化」から初期状態に戻せます。

## サンプルデータについて

仕様の「確認中 3/5 人」と、既定条件の「3 人以上で確認済み」を同時に表現するため、サンプルの「明日の部活動について」のみ必要確認人数を 4 人に設定しています。新しく投稿する連絡は既定どおり 3 人で確認済みになります。

## 注意事項

- このリポジトリはローカル動作用のプロトタイプです。外部データベースや実際のプッシュ通知は使用していません。
- データは利用中のブラウザーの localStorage に保存されます。ブラウザーデータを消去すると内容も削除されます。
- 認証はデモ用の簡易実装です。実運用向けの本人確認や権限管理は含まれていません。
- 学校の正式な連絡手段を置き換えるものではありません。
